<threat_model>
### Security Threat Model:
1. **Sensor Line Disconnection (Tampering)**:
   - Threat: An attacker cuts the signal lines of the sensors.
   - Analysis: For the SW-520D Tilt Sensor configured with `INPUT_PULLUP`, cutting the line floats the pin HIGH, which is interpreted as the "Upright/Safe" state.
   - Mitigation: In v1, this is documented as a physical vulnerability. In future milestones, a normally-closed loop configuration can be explored.
2. **Transducer Sabotage (Auditory Bypass)**:
   - Threat: Physically breaking the buzzer to silence the alarm.
   - Mitigation: Simultaneous dual alerting (both flashing LED and Serial logs) ensures visual and diagnostic traces remain functional.
</threat_model>
